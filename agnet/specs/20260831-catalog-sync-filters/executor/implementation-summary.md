# 实现摘要

- 将八个配件分类的稳定 Fixture 扩展到每类至少 12 个，显卡补充具体板卡厂商与型号。
- 新增公开目录解析、固定 URL 白名单、响应限制、SQLite 缓存、同步状态与合并去重。
- 复用持久化队列和 SSE 增加目录更新任务，网络失败、解析失败或服务停用时保留已有候选。
- 扩展目录接口的搜索、厂商、类型/系列、价格区间、排序和分面数据。
- 重构配件选择器，列表直接展示图片、厂商、型号、关键参数、参考价、来源和更新时间。
- 增加厂商/系列快捷项、最低/最高价、手动更新、任务进度和响应式布局。
- 更新环境变量示例、README、迁移和脱敏 Spec 记录。

# 数据边界

- 只请求代码内固定的八个 ZOL 公开产品列表 URL。
- 不携带 Cookie，不使用登录态，不跟随重定向，不绕过验证码或访问控制。
- 外部参考价不作为实时最低价或成交价承诺；兼容参数缺失时保持待确认。

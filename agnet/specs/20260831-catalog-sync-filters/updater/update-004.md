# 功能更新方案

## 1. 更新背景

用户输入 ¥2,500 后，演示方案仍按固定配件价格和方案倍率计算，结果可能继续显示约 ¥12,000 的总价，预算没有真正参与选型与提示。候选详情中的京东、拼多多报价目前由目录参考价乘固定比例生成，虽然标注了“示例 / 未联网”，但会造成店铺、金额和采集时间看起来像真实商品数据。

用户提供的 ZOL 参数页需要作为公开规格来源进行校准。该页面包含型号、B760 芯片组、LGA1700、DDR4、Micro ATX、尺寸以及公开参考价格等字段；缺失字段应继续显示“待确认”，不能从型号名称猜测。

另外，自然语言输入“8000元玩战争雷霆的游戏主机”时，预算和分辨率恰好与默认演示值相同，页面没有显式展示游戏识别结果，用户容易误以为输入没有生效。需要把 War Thunder 识别为本地可用的 Steam 游戏，并在需求面板显示最低/推荐配置已载入。

## 2. 更新目标

- 修复预算传递链路，让 ¥2,500、普通预算和高预算都影响演示方案、总价、预算提示和 API 生成请求。
- 对确实无法覆盖完整独立显卡整机的预算，给出清晰的“预算不足/需要已有配件/建议提高预算”说明，不使用不真实的价格凑数。
- 移除由固定比例推导的虚构京东、拼多多金额、店铺和新鲜采集时间；没有可验证报价时显示待联网状态和平台搜索入口。
- 增加受控的 ZOL 公开详情页解析，读取用户提供的 `detail.zol.com.cn` 参数页，并将可验证字段合并到商品详情；不绕过登录、验证码、访问控制或反爬。
- 区分“目录参考价”“公开页参考价”“实时授权报价”和“待联网”，让商品参数与价格来源可追溯。
- 保持现有候选切换、兼容性检查、预算输入、API/Worker 和离线演示回退可用。
- 识别“战争雷霆”、War Thunder 等游戏别名，载入最低/推荐配置并给出明确的查看入口；初始化请求完成或失败时不得覆盖用户刚提交的需求。

## 3. 实现范围

- `apps/web/src/App.tsx`：调整演示方案的预算感知选型/预算提示，确保低预算不再沿用固定高价组合；展示准确的数据状态。
- `apps/web/src/types.ts` 与 `apps/api/app/domain.py`：补充报价可用性或公开参考价语义，兼容已有实时报价响应。
- `apps/web/src/features/catalog/OfferComparison.tsx`、`ProductDetailPage.tsx`：无真实金额时不渲染伪造数值，展示来源状态、核价入口和参数来源。
- `apps/api/app/features/products/service.py`：删除固定比例平台报价生成；新增严格白名单 ZOL 详情 URL 校验、HTML 参数/参考价解析和来源证据。
- `apps/api/app/config.py`：预留 ZOL 详情页映射配置，默认只允许公开 HTTPS 页面。
- `apps/api/tests/` 与 `apps/web/src/*.test.tsx`：覆盖 ¥2,500 预算、预算不足提示、无报价状态、ZOL 参数字段映射、来源状态、战争雷霆自然语言识别和原有回归。
- `plan.md` 与当前 Spec：同步真实完成状态，不记录内部逐步思考原文。

## 4. 数据边界与安全约束

- ZOL 仅作为公开规格和参考价格来源；解析使用固定主机、固定路径格式、超时、响应大小和不跟随重定向限制。
- 京东、拼多多和淘宝只有在已有受控连接器返回明确商品、店铺、金额和采集时间时才标记为实时或公开参考；否则不显示推导金额。
- 不把 ZOL 参考价、Fixture 价格或搜索结果页价格冒充最终到手价，不伪造店铺和采集时间。
- 不使用登录态，不实现验证码绕过、反爬绕过或隐藏式大规模抓取；外部失败时保留可解释的本地回退。

## 5. 验收标准

- [x] 输入 ¥2,500 后，生成请求和页面方案预算均为 ¥2,500；总价、预算差额和提示不再固定使用默认高预算。
- [x] 预算无法覆盖完整配置时，页面显示明确原因和可执行建议；不通过修改商品价格或生成虚构商品来伪造预算内方案。
- [x] 未取得京东/拼多多实时或公开可验证金额时，不显示由 `part.price` 乘比例得到的金额、店铺或虚假采集时间；用户仍能打开平台搜索入口。
- [x] 解析用户提供的 ZOL 页面时，能保留标题、芯片组、CPU 插槽、内存类型/容量、板型、尺寸、扩展接口和公开参考价等字段；未知字段保留，缺失字段显示待确认。
- [x] 详情页清晰区分 Fixture、本地目录、ZOL 公开参考和实时授权报价，来源链接与状态一致。
- [x] 输入“8000元玩战争雷霆的游戏主机”后，需求面板保留 8,000 元预算，显示已识别 War Thunder，并可打开最低与推荐配置；API 侧至少将其识别为游戏用途。
- [x] 后端 Ruff、mypy、Pytest 与前端类型检查、Vitest、生产构建全部通过；既有候选、换件、兼容性、导出和演示回退测试不回归。

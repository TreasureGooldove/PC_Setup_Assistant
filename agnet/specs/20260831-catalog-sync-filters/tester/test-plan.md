# 测试计划

- 目录：八个分类各不少于 12 个 Fixture，ID 唯一，兼容性核心字段完整。
- 解析：GBK/HTML 样例可提取名称、摘要、价格、图片和详情链接；非白名单与超限响应被拒绝。
- 缓存：保存后可读取，重复项按 ID/名称去重，失败不删除上次成功数据。
- 筛选：关键词、品牌、类型/系列、最低价、最高价和排序组合生效，分面数量正确。
- 队列：刷新任务可完成、进度可见、幂等键有效，未开启或网络失败时状态明确。
- 并发：20 个目录读取无 SQLite 锁死，结果一致。
- 前端：品牌/类型芯片、价格区间、清空、同步状态、图片占位和选用流程可用。
- 回归：Ruff、Mypy、Pytest、前端 lint/typecheck/Vitest/build、迁移与秘密扫描。

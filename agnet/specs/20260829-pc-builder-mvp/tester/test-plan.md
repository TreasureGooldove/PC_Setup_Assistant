# 测试计划

## 验收标准

- 后端 Ruff、Mypy、Pytest 通过；前端 lint、测试和生产构建通过。
- 默认 Fixture 可生成三套方案，兼容性硬规则能识别错误。
- JobQueue 具备幂等、重试、租约、取消和 SSE 状态。
- 浏览器可完成需求输入、方案切换、替换/锁定和导出入口。

## 测试用例

| 编号 | 描述 | 预期 |
|---|---|---|
| TC-001 | 默认需求生成方案 | 返回三套方案且默认组合无错误 |
| TC-002 | 自然语言需求解析 | 预算、品牌、散热和分辨率进入 NeedProfile |
| TC-003 | 兼容性异常 | 插槽、内存、空间和电源问题被识别 |
| TC-004 | 队列幂等与恢复 | 相同键不重复，失败任务可重试 |
| TC-005 | Excel 导出 | 生成概览、配件明细和兼容性工作表 |
| TC-006 | Web 工作台 | 375px 到桌面宽度均可交互，无横向滚动 |

## 证据规则

测试输出必须由测试命令自动生成，证据放入本 Spec 的 `tester/artifacts/`；不得保存 Token、Cookie、密钥或真实用户隐私。

# 实现摘要

- 扩展硬件目录到 18 个 CPU、20 个 GPU、16 个主板候选，并补齐主板芯片组、插槽、板型、内存、M.2、SATA、PCIe、Wi-Fi、供电和灯光字段。
- 天梯改为从统一目录派生，条目可回到同 ID 配件；使用 ZOL CPU/GPU 天梯链接作为结构参考，展示本地归一化分数。
- 增加 `GET /api/products/{part_id}`，聚合配件、京东/拼多多报价、证据和 Provider 状态。
- 增加京东公开商品页标题、JSON-LD 与 `dt/dd` 参数解析；只允许 HTTPS `item.jd.com/<数字>.html`，默认关闭并带稳定回退。
- 配置项主体改为语义化按钮，点击型号即可换件；选配器增加商品详情入口。
- 增加独立商品详情页，展示双平台报价、参数、优缺点、信源、实时/示例状态和直接使用按钮。
- 修正扩充目录后自动规划总选最高端型号的问题，改为按方案目标分选择并限制常规机箱显卡长度。

## 数据边界

- 京东和拼多多的默认价格是明确标记的 Fixture 示例，不声称实时或最低价。
- 京东公开页解析不使用 Cookie、登录态、页面脚本、指纹伪装、验证码或反爬绕过。
- ZOL 页面仅用于字段结构、型号层级与人工核对链接，应用排名是本地归一化结果。

# 测试计划

- 目录：CPU/GPU 数量不少于 15，主板不少于 10，ID 唯一，核心兼容字段完整。
- 天梯：按排名排序、筛选有效，条目可映射回目录配件，来源指向相应 ZOL 天梯。
- 京东解析：样例 HTML 可提取标题和参数；拒绝非 HTTPS、非 `item.jd.com` 与可疑 URL。
- 商品详情：已知型号返回京东和拼多多报价、证据及状态；未知型号返回统一 404。
- 前端：点击配置项主体可打开选配器；候选可进入商品详情；详情显示双平台报价、参数和使用按钮。
- 回归：后端 Ruff、类型检查、Pytest；前端 lint、类型检查、Vitest、生产构建；秘密扫描。

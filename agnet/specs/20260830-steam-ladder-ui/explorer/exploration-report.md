# 探索结论

- 现有页面已具备需求对话、三档方案、兼容性检查、替换/锁定和导出能力，适合增加顶部视图切换。
- 参考站点公开页面强调配置选择、价格汇总、组件数量和问答入口；本次提取信息层级，不复制品牌和素材。
- 天梯需要稳定的结构：类别、档位、排名、型号、性能参考、显存/功耗和参考价。
- Steam 游戏配置需要区分最低与推荐，保存操作系统、处理器、内存、显卡、存储空间和 DirectX 等字段；外部 API 未配置时必须可运行。
- 采用 feature-first：`games` 与 `ladder` 领域模块分别提供数据与路由，前端用独立视图呈现。
